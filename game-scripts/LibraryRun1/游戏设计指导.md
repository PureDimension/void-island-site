# 游戏设计指导
整个游戏会由3个大关&关卡之前之间之后的4段剧情组成。
在剧情演出段，游戏的前端表现为若干文字信息，点击则进入下一页。
在关卡时，前端表现将会把我方单位、敌方单位和敌方的行动逻辑列出。右侧将会显示选中单位的详细信息。玩家可以选择一个我方单位攻击地方单位。

# 战斗能力指导
所有单位的能力和BUFF（BUFF可以看作是一种自由赋予的能力）可以具有如下分类：
战斗前能力：战斗前发动
战斗时能力：战斗时发动
战斗后能力：战斗结束后发动
被动能力：产生后永久生效
...（可扩展）

特殊能力（不常见且不单独出现，是描述前述能力额外限制的一些能力）：
广域能力：即使自己未进入战斗，也会对其他符合条件的单位生效，应当特别考虑。
主动能力：在游戏的非战斗时刻可以选择发动能力并应用其效果。
...（可扩展）
